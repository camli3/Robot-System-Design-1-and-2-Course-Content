## e1_a1　PID × 悬停

**此时无人机状态：** 只做垂直爬升并悬停，水平位置、偏航保持 0。机身始终水平，不滚转、不俯仰。

### e1_a1_traj3d.png

- **含义：** 绿点出发，沿 z 升到约 1 m 的一条竖直线。
- **为何这样：** 任务只有高度变化，x=y=0。红线盖住蓝虚线，说明实际路径与期望几乎重合。
- **参数：** 见上表 traj3d。

### e1_a1_pos_err.png

- **含义：** \(e_x,e_y\) 贴 0；\(e_z\) 先正后负，峰值约 2.7 mm。
- **为何这样：** 水平无指令，误差为 0。高度用五次多项式爬升，PID 略滞后：前半段实际低于期望（\(e_z>0\)），过中点后略超前再收回。纵轴 \(\times10^{-3}\)，不是米级误差。
- **参数：** \(e_x,e_y,e_z\)。

### e1_a1_att.png

- **含义：** \(\phi,\theta,\psi,\phi_d,\theta_d\) 全部为 0° 的一条水平线。
- **为何这样：** 纯垂直运动不需要倾斜，期望姿态也是 0，五条线重叠。
- **参数：** \(\phi,\theta,\psi,\phi_d,\theta_d\)。

### e1_a1_rate.png

- **含义：** \(p=q=r=0\)，一条直线。
- **为何这样：** 姿态不变，没有转动。
- **参数：** \(p,q,r\)。

### e1_a1_u.png

- **含义：** \(U_1\approx9.8\sim10\) N 近平线；\(U_2=U_3=U_4=0\)。
- **为何这样：** 悬停/慢爬只需略大于或接近重力的总推力，不需要力矩。
- **参数：** \(U_1\sim U_4\)。

## e1_a2　反步 × 悬停

**此时无人机状态：** 与 e1_a1 相同，只换控制律。仍是垂直悬停，机身水平。

### e1_a2_traj3d.png

- **含义 / 为何：** 同 e1_a1，竖直线、红蓝重合。反步也能走这条高度指令。

### e1_a2_pos_err.png

- **含义：** 仍是毫米级 \(e_z\)，\(e_x=e_y=0\)。RMSE 略大于 PID（0.0021 vs 0.0015），但末端误差几乎为 0（积分后 PID 有一点残差，反步末端更贴）。
- **为何这样：** 垂直通道两种算法都能跟；反步按误差递推，稳态收得更死，过程 RMSE 略大。

### e1_a2_att.png / e1_a2_rate.png

- **含义 / 为何：** 与 e1_a1 一样是 0 直线。垂直飞不转姿态，与用哪种算法无关。

### e1_a2_u.png

- **含义 / 为何：** 同 e1_a1，\(U_1\approx mg\)，力矩为 0。

## e2_a1　PID × 升降

**此时无人机状态：** 先爬到 1 m，再升到 2 m，再降到 0.5 m。全程 x=y=0，机身保持水平。仿真约 23 s（三段各 6 s + 末段悬停）。

### e2_a1_traj3d.png

- **含义：** 比 e1 更高的一条竖直线（z 到 2 m）。
- **为何这样：** 只有高度往返，俯视仍是一个点。红线盖住蓝线。

### e2_a1_pos_err.png

- **含义：** \(e_x=e_y=0\)；\(e_z\) 出现多段波峰波谷，最大约 −10 mm（约 15 s，从 2 m 往 0.5 m 下潜时）。
- **为何这样：** 每换一段高度指令，PID 高度环都有一次滞后/超调。下行段加速度更大，\(e_z\) 负峰更明显。仍是毫米级。

### e2_a1_att.png / e2_a1_rate.png

- **含义 / 为何：** 仍是 0 直线。升降不靠倾斜，靠 \(U_1\) 加减。

### e2_a1_u.png

- **含义：** \(U_1\) 在 9.8 N 附近随爬升/下降微微起伏；力矩为 0。
- **为何这样：** 加速向上 \(U_1>mg\)，减速或下降 \(U_1\) 略减。

## e3_a1　PID × 前后

**此时无人机状态：** 0–6 s 先垂直到 (0,0,1)；之后机头方向（+x）飞到 x=2，再回到 x=0，高度保持 1 m。要产生水平加速度必须**俯仰**（\(\theta\)）：加速向前时抬头或低头（本模型 +x 对应 \(+\theta\)），刹车时反向倾斜。滚转、偏航保持 0。

### e3_a1_traj3d.png

- **含义：** 先竖直线，再沿 x 折到 2 m 再折回，像「倒 L + 来回」。
- **为何这样：** 任务就是「先爬高再前后」。红线几乎盖住蓝线。

### e3_a1_pos_err.png

- **含义：** 前 6 s 只有小 \(e_z\)（爬高）；6 s 后 \(e_x\) 出现 ±0.02 m 量级的正负峰；\(e_y\approx0\)。
- **为何这样：** 水平运动靠倾斜间接实现，位置环必然有滞后：去程实际落后于期望（\(e_x>0\)），回程反向（\(e_x<0\)）。侧向无指令故 \(e_y=0\)。

### e3_a1_att.png

- **含义：** \(\theta\) 与 \(\theta_d\) 几乎重合，峰值约 ±2.1°；\(\phi,\psi\approx0\)。
- **为何这样：** 前后只需要俯仰。虚线期望与实线实际贴在一起，说明内环跟上了。倾角很小是因为水平加速度不大、限幅远未用满。

### e3_a1_rate.png

- **含义：** 只有 \(q\) 在换段时出尖峰（约 ±0.058 rad/s），随后回到 0；\(p=r=0\)。
- **为何这样：** 开始俯仰/回正时角速度最大。峰后回到 0 是正常机动，不是发散。

### e3_a1_u.png

- **含义：** \(U_1\) 仍在 10 N 附近；换段时 \(U_3\)（俯仰力矩）有小尖峰，\(U_2=U_4=0\)。
- **为何这样：** 改 \(\theta\) 靠俯仰力矩；总推力仍主要抗重力。

## e3_a2　反步 × 前后

**此时无人机状态：** 与 e3_a1 同一条前后航线。

### e3_a2_traj3d.png

- **含义 / 为何：** 同 e3_a1 的「先升后沿 x 来回」。跟踪同样紧。

### e3_a2_pos_err.png

- **含义：** 仍是 \(e_x\) 主导，但 RMSE 0.0066、末端 0.0002，明显小于 PID（0.011 / 0.003）。
- **为何这样：** 反步用虚拟速度/加速度递推，水平跟踪比串级 PID 更紧。

### e3_a2_att.png

- **含义：** 仍是 \(\theta\) 约 ±2° 的脉冲，与 \(\theta_d\) 重合；\(\phi=\psi=0\)。
- **为何这样：** 同一物理任务，倾角需求差不多；反步内环同样能跟上。

### e3_a2_rate.png

- **含义：** \(q\) 尖峰略高于 PID（max \(\|\omega\|\) 0.070 vs 0.058），仍回到 0。
- **为何这样：** 跟得更紧时姿态切换略更急，角速度峰略大，但未发散。

### e3_a2_u.png

- **含义 / 为何：** 与 e3_a1 同类，主要是 \(U_1\) + 换段时的 \(U_3\)。

## e4_a1　PID × 左右

**此时无人机状态：** 与 e3 对称：先到 1 m，再沿 **y** 走 0→2→0。水平加速度靠**滚转** \(\phi\)，不俯仰。机身左右倾，机头朝向不变。

### e4_a1_traj3d.png

- **含义：** 先升高，再沿 y 来回，折线在 yz 平面。
- **为何这样：** 任务是左右平移。因对称，精度指标与 e3_a1 完全相同。

### e4_a1_pos_err.png

- **含义：** \(e_y\) 出现与 e3 中 \(e_x\) 相同形状的 ±2 cm 级误差；\(e_x\approx0\)。
- **为何这样：** 只是把前后通道换成左右通道。

### e4_a1_att.png

- **含义：** \(\phi\)（不是 \(\theta\)）约 ±2.1°，与 \(\phi_d\) 重合。
- **为何这样：** 左右用滚转。\(+\phi\) 与 \(-\)y 加速度的对应由旋转矩阵决定。

### e4_a1_rate.png

- **含义：** 只有 \(p\) 有尖峰（对应 e3 的 \(q\)），\(q=r=0\)。
- **为何这样：** 滚转通道的角速度。

### e4_a1_u.png

- **含义：** 换段时动的是 \(U_2\)（滚转力矩），不是 \(U_3\)。
- **为何这样：** 改 \(\phi\) 靠 \(U_2\)。

## e4_a2　反步 × 左右

**此时无人机状态：** 与 e4_a1 同一条左右航线。

### e4_a2_traj3d.png

- **含义 / 为何：** 同 e4_a1 折线。红蓝重合。

### e4_a2_pos_err.png

- **含义：** \(e_y\) 为主，RMSE/末端与 e3_a2 相同（优于 PID）。
- **为何这样：** 对称 + 反步水平跟踪更紧。

### e4_a2_att.png

- **含义：** 蓝线 \(\phi\) 在约 6–18 s 出现 −2° / +2° 的脉冲（去程侧倾、回程反向），与 \(\phi_d\) 重叠；\(\theta=\psi=0\)。
- **为何这样：** 先向 +y 加速要侧倾，到点刹车要反倾，再飞回时再反一次。实际与期望重合 = 内环良好。

### e4_a2_rate.png

- **含义：** \(p\) 在换倾角时出峰，回到 0。max \(\|\omega\|\) 同 e3_a2。
- **为何这样：** 滚转角速度，不是发散。

### e4_a2_u.png

- **含义 / 为何：** \(U_1\approx mg\)，换段时 \(U_2\) 有小力矩。

## e5_a1　PID × 五航点

**此时无人机状态：** 约 39 s。先垂直到 (0,0,1)，再按固定随机种子飞 5 个点（平面 ±2 m，高度 0.8–2.0 m）。每段五次多项式平滑，到点速度为 0 再切下一目标。机身要在水平面内不断改倾角方向，\(\phi\) 与 \(\theta\) 都会动，偏航指令仍为 0。

### e5_a1_traj3d.png

- **含义：** 折线空间轨迹（先升高再连 5 点）。末端能看到一点蓝虚线。
- **为何这样：** 多航点三维折线。PID 误差约 2 cm，拐角处红蓝会略分开，故能看见蓝线。

### e5_a1_pos_err.png

- **含义：** \(e_x,e_y,e_z\) 都随换点起伏，峰值约 2 cm 量级；RMSE 0.020 为十组里最大。
- **为何这样：** 同时改 x/y/z，欠驱动（先倾再平移）使位置环来不及，每换一点误差跳一次。

### e5_a1_att.png

- **含义：** \(\phi,\theta\) 多次在约 ±3.6° 内变化，并跟踪 \(\phi_d,\theta_d\)；\(\psi\approx0\)。
- **为何这样：** 每个航点的水平加速度方向不同，期望倾角方向跟着变。最大倾角仍远小于 25° 限幅。

### e5_a1_rate.png

- **含义：** \(p,q\) 在每次换点出现尖峰（最大约 0.15 rad/s），随后回到 0；\(r\approx0\)。
- **为何这样：** 换倾斜方向 = 短时角速度。峰后收敛说明未发散。PPT 要看的「角速度超调」就在这些尖峰，幅度可控。

### e5_a1_u.png

- **含义：** \(U_1\) 在 10 N 附近随高度微调（约 9.5–10.2）；\(U_2,U_3\) 相对 \(U_1\) 很小，图上几乎贴 0；\(U_4=0\)。
- **为何这样：** 力矩只需扭动小惯量，数值远小于推力，和 \(U_1\) 画在同一纵轴时看起来像直线。不是没输出力矩。

## e5_a2　反步 × 五航点

**此时无人机状态：** 与 e5_a1 同一组随机航点，便于公平对比。

### e5_a2_traj3d.png

- **含义 / 为何：** 折线与 e5_a1 同一形状。跟踪更紧，蓝线更难看见。

### e5_a2_pos_err.png

- **含义：** 三轴误差仍在换点时出峰，但峰值约 1.5–2 cm，RMSE 0.0116（约为 PID 的一半），末端 0.0058。
- **为何这样：** 反步虚拟控制把位置/速度误差一起压，复杂轨迹上优势更明显。这是报告里「双算法对比」的主证据。

### e5_a2_att.png

- **含义：** \(\phi,\theta\) 随航点变化，最大倾角 3.37°（略小于 PID 的 3.58°），与期望重合。
- **为何这样：** 同一航点所需倾角相近；跟得更准时不必把姿态拉得更大。

### e5_a2_rate.png

- **含义：** \(p,q\) 尖峰比 PID 略高（0.173 vs 0.149），每次换点后回到 0。
- **为何这样：** 跟得紧 → 姿态切得稍急 → 角速度超调略大，但仍收敛。报告可写：反步精度更好，角速度代价略增。

### e5_a2_u.png

- **含义 / 为何：** 与 e5_a1 同类，\(U_1\) 扛重力，力矩相对很小。

## 读图时怎么写报告

1. **e1/e2 的 att、rate 是直线：** 只垂直飞，不是程序没画。
2. **traj3d 看不见蓝线：** 跟踪到厘米/毫米，红线盖住期望，用 pos_err 看差别。
3. **e3 看 \(\theta,q,U_3,e_x\)；e4 看 \(\phi,p,U_2,e_y\)：** 前后/左右对称。
4. **e5 最能体现 PPT「复杂轨迹」：** 优先贴 e5 的 traj3d、pos_err、rate。
5. **算法结论：** 垂直机动两者都很好；水平/多航点 **反步 RMSE 更小**，角速度峰略大但仍稳定。
6. **未发散判据：** rate 有峰但回到 0，倾角 < 4°，位置误差不随时间放大。
